# 진행 속도 시뮬레이션 결과

`npm run sim`(tools/simulate.mjs)으로 생성한 결과다. 시드 100개, 칸 복권 생성기(js/cards.js)와 계산대 규칙(js/economy.js의 REGISTER)을 그대로 써서 1회차부터 무한 모드 1시간까지 돌렸다. 함정 복권은 버리지 않고 끝까지 연다고 가정했다(보수적).

플레이어 모델은 단순화한 가정이다. 가정은 기획서 7장에 적었다.
- 직접 긁는 시간은 브라우저에서 실제로 손가락 움직임을 흉내 내 잰 값(tools/dev/scratch-feel.mjs)에 맞췄다.
- 계산대는 물건마다 "정확/좋음/놓침"을 정해진 비율로 뽑는다.
